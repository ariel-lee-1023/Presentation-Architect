# Fidelity ledger

Maintainer records only; normal domain answers should load SKILL.md and relevant runtime references.

- `source-manifest.json`: supplied filenames, hashes, PDF page counts, editions, coverage and omissions.
- `coverage.md`: source recovery, visual checks, synthesis boundaries and budget decisions.
- `reading-requests-original.json`: original MD request log; not proof that truncated outputs were fully read.
- `reading-ledger.json` and `reading-report.json`: annotated request-span accounting with explicit limitations.
- `pdf-reading-ledger.json`: separate PDF page requests.
- `editorial-review.md`: source/decision inspection, distinct from model evaluation.
- `acceptance-suite.json`, `acceptance-status.json`, `evaluation.md`: frozen tasks and honest unrun status.
- `validation/`: actual structural, budget, scan, link and suite-check outputs.

Raw books, full extracted text, source-page renders and credentials are intentionally excluded.
